# PLAN.md

Landing page first, one hour. Then the milestones from PRODUCT.md, with
the riskiest part first and each milestone kept as small as possible.

1. I can see the landing page and start the product.
2. I can capture a health update by voice or text.
3. I can see what the AI understood and edit it before saving.
4. I can save a confirmed health event.
5. I can see the event in the patient's health timeline.
6. I can create one patient with a name and relationship.
7. I can edit or delete a previous health event.
8. I can capture different kinds of health information through the same
workflow.
9. I can get an evidence-grounded summary for a selected period.
10. I can see meaningful changes and patterns without diagnosis or
treatment advice.
11. I can generate a concise doctor-ready brief.
12. I can review and edit the doctor brief before sharing.
13. I can share the doctor brief using the device's native sharing
mechanism.
14. I can return to the product, authenticate, and continue with the
same patient and timeline.

Last: I can close it, reopen it, and my data is still there.
